# Attributions

Pixel Agents builds on the work of generous pixel artists. Thank you!

## Characters

The office characters are based on [JIK-A-4's Metro City pack](https://jik-a-4.itch.io/metrocity-free-topdown-character-pack): six diverse top-down character designs. Pixel Agents further diversifies them at runtime with hue shifts, so any number of agents stay visually distinguishable.

## Furniture

The furniture set was created by [Pablo De Lucca](https://pablodelucca.com), inspired by [Donarg's Office Interior Tileset](https://donarg.itch.io/officetileset).

## Pets

The pets were created by [ItsManeka](https://itsmaneka.itch.io) ([GitHub](https://github.com/itsManeka)).

## Your work here

If you publish an asset pack for Pixel Agents and want it credited here, open a PR against this page - see [external assets](/use/workflows/external-assets) and [publishing a pack](/build/assets/publishing-a-pack).
