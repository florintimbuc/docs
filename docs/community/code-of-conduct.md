# Code of Conduct

Pixel Agents follows a Code of Conduct that applies to all project spaces: GitHub repos, Discussions, issues, PRs, Discord, and any other community channel associated with the project.

## The canonical document

The full Code of Conduct lives in the repo: [CODE_OF_CONDUCT.md](https://github.com/pixel-agents-hq/pixel-agents/blob/main/CODE_OF_CONDUCT.md). Read it in full.

## In short

We're committed to making participation in this project a respectful, harassment-free experience for everyone, regardless of:

- Age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## What's expected

- **Be welcoming.** Most contributors are new to the project. Treat them the way you wanted to be treated on your first contribution.
- **Be patient.** Maintainers volunteer time. Contributors learn over time. Allow space for misunderstandings to be resolved.
- **Disagree respectfully.** Technical disagreement is fine. Personal attacks are not.
- **Focus on the code, not the person.** "This approach has a problem because..." not "you don't understand this".
- **Accept feedback gracefully.** Code review is a normal part of the process. Suggestions are not insults.

## What's not tolerated

- Harassment, intimidation, or discrimination in any form.
- Personal attacks or insults.
- Sexual language or imagery in project spaces.
- Public or private harassment.
- Publishing others' private information (doxxing) without explicit permission.
- Other conduct which could reasonably be considered inappropriate in a professional setting.

This applies to maintainers, contributors, and bystanders alike.

## Reporting

If you witness or experience unacceptable behavior in any Pixel Agents space:

1. **For acute or sensitive situations**, contact the maintainers privately. Use the email listed in [SECURITY.md](https://github.com/pixel-agents-hq/pixel-agents/blob/main/SECURITY.md) or reach out via Discord DM to a maintainer.
2. **For public-but-clearly-unacceptable behavior** (e.g. a hostile comment on a public GitHub issue), it's also fine to publicly call out that the behavior crosses the line, then let the maintainers handle it from there.
3. **Do not retaliate.** Let maintainers act.

Reports are taken seriously. Maintainers will respond within 48 hours to confirm receipt and will follow up with the reporter on the outcome.

## Enforcement

Maintainers may take any action they deem appropriate, including:

- A private warning.
- A public apology requirement.
- A temporary ban from one or more project spaces.
- A permanent ban from all project spaces.

The severity of the response depends on the severity of the conduct and any history. Maintainers will not disclose the identity of reporters without consent.

If you disagree with an enforcement action and want it reviewed, contact the maintainers (via the same channels as reporting) and the situation will be reviewed.

## Scope

This Code of Conduct applies to all project spaces. Behavior outside those spaces is generally not the project's concern unless it affects the project (e.g. doxxing a contributor for their PR is in scope even if the doxxing happens elsewhere).

Contributions from contributors with a documented history of conduct issues in this project may be declined regardless of the contribution's merit.

## Adapted from

The Pixel Agents Code of Conduct is adapted from the Contributor Covenant. The full original text is available at [contributor-covenant.org](https://www.contributor-covenant.org/).

## Updates

This Code of Conduct may be updated as the community grows or as new situations arise. Changes are PR-reviewed like any other content. The version in the repo is canonical.
